# Lumior 组件与颜色审查台

当前暗色产品已接入 **44 项规范色（38 个不同色值）**，包括透明色；尚未发布桌面更新。默认页为每项颜色展示组件配色示例，可以左右比较替换效果。


这是独立本地审查工具，不是产品页面。不会读取桌面工作区、调用模型或修改产品主题。

启动：在项目根目录执行 `pnpm design:dev`（等价于 `node scripts/design-system.mjs`）。默认地址为 `http://127.0.0.1:42829/`。启动前自动重新扫描源码。

构建：`pnpm design:build`。静态产物位于 `output/design-system/site/`，应通过本地 HTTP 服务浏览。扫描单独执行 `pnpm design:scan`。

## 这版能做什么

- 44 项规范色：44 个组件配色示例、用色区域定位、默认 / 悬停对照、左右换色比较、替代色原有用途、直接及别名引用。可按用途或组件名称搜索。
- 合并试配：可以保留多组替换、标记未使用色为删除候选，自动统计不同色值数；支持链式替换，阻止循环。同色用途不会虚增减少数量。建议自动保存在当前浏览器，独立导出 `lumior-color-merge-review.json`；重置只清空审查台试配。

- 系统总览：模块、基础规则与覆盖范围。
- 组件与状态：直接引用 Button、Input、Textarea、Checkbox、Switch、Badge、Tabs、DropdownMenu、Tooltip 与论文删除提醒；菜单附加样式从产品 CSS 原样抽取。论文阶段为使用产品 CSS 的样本结构。
- 颜色用在哪里：点击色块，查看模块、源码位置、选择器、属性；可按模块、值、路径筛选，另外查看现有 CSS 变量定义和引用。
- 规范检查：区分已验证通过、确定的问题、待讨论的方向及不可全局替换的内容颜色。
- 明暗色方案：25 个用途色，分别修改明暗值、恢复默认、预览文字对比度；主操作按钮与荧光绿品牌强调分开，暗色白底深字、亮色近黑底白字。场景明确标为方案示意，不冒充已完成的产品亮色版本。
- 全量模块清单：自有 TSX 文件及直接源码引用，未检出引用不代表可以删除。
- 导出明暗配色：下载 JSON，保留明暗方案与“已看过”标记；这部分刷新会重置未导出的调整。它与上面的合并建议分开，二者都不应用到产品。

## 每项颜色的组件示例

`color-examples.json` 为每个颜色用途登记一个代表场景、具体用色位置、当前源码声明与状态。Button 直接使用产品组件；其余原型复用色板与对应组件的关键颜色声明，布局有所简化，明确标注「配色原型」。未使用色只展示「假设示例」，不能据此声称产品里有该控件。

每个示例打开后，左侧固定生产色板，右侧使用试配色板。点击「定位用色区域」查看作用层；选择替代色后即时比较，可展开替代色本来的组件场景。原型中的输入、切换和点击仅改变演示状态，不读取工作区、删除资料或发起 AI 请求。保留试配只写本地审查台的独立存储项。

当前优先候选：未检出 `success-soft` 产品引用；`line-subtle` / `fill-hover` 与 `line` / `fill-pressed` 分别已同色；标准 / 深阴影仍可试配比较。`fill-pressed` 实际也用于开关和滚动条，名称需要后续讨论。上述候选未额外应用产品。

用户已确认的四组合并已应用产品色板：普通 / 突出控件共用 `#303133`；次要 / 辅助文字共用 `#a3a3a3`；主要文字 / 白底动作共用 `#ffffff`；浅底深字 / 内容表面共用 `#191919`。保留各自用途名称供后续亮色映射，色值由 42 降至 38；选中白色 10%、悬停、按下和表面层级保持独立。

## 数据边界与更新

`generated/audit.json` 来自 `app/` 与 `components/`：CSS 声明通过 PostCSS 解析，TS / TSX 的明确颜色字面量通过 TypeScript 语法树提取。排除第三方 vendor；包含独立预览、未使用原语和用户内容调色板。命名色、动态表达式、第三方内部样式及实际级联上下文未穷尽，不能将原始次数当作违规数。

`reference.ts` 维护场景使用说明和审查项，暗色从 `ui-palette.json` 读取，亮色为独立建议值。手动预览调色不会自动写回产品。

当前扫描为 91 个自有 CSS 文件、179 个 TSX 源文件（65 个基础组件）、138 种颜色写法；界面色板 44 项用途，未登记界面字面量为 0。数量随源码变化更新。

## 颜色维护（2026-10-25）

真值：`ui-palette.json`。同步：`node scripts/sync-ui-colors.mjs`。检查：`node scripts/check-ui-colors.mjs`。运行命令时位于项目根目录。

颜色写法扫描首次由 719 降到 142，四组灰阶合并后为 138；包含 156 处内容色使用位置和色板定义。44 是界面用途上限的当前占用，不是整个产品渲染出来的像素颜色数量。后续构建会检查色板不超过 50 项及受管代码不新增零散色。

内容色边界由 `scripts/ui-color-policy.mjs` 记录；PDF 高亮、用户分区、标签、壁纸和品牌等保留原样。亮色仍是预览，不是可发布的产品主题。
