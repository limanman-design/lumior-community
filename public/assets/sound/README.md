# Sound player icons

Google Material Symbols **Rounded**, optical size 20px, weight 400, grade 0. Rendered locally as masks to inherit each control's color.

Source: https://fonts.google.com/icons?icon.size=20&icon.style=Rounded

SVG download pattern: `https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/{name}/default/20px.svg`

The play and pause controls use **FILL 1** (filled), downloaded on 2026-10-10:

| Local asset | Exact Google Fonts download |
| --- | --- |
| `play_arrow.svg` | https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/play_arrow/fill1/20px.svg |
| `pause.svg` | https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/pause/fill1/20px.svg |
| `tune.svg` | https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsrounded/tune/default/20px.svg |

`tune.svg` uses the default FILL 0 setting and identifies the full sound-player settings panel. Other icons retain their original default FILL 0 assets.

Google's [Material Symbols guide](https://developers.google.com/fonts/docs/material_symbols) defines FILL 1 as completely filled and documents the SVG download options.
