## 本批 PR · 画布交互与笔记编辑（R-019～R-022）

- R-019：对话窗和对话历史展开增加揭开/淡入动效，尊重系统减少动态效果设置；固定对话选中仅图标着色，输入提示降低一个既有颜色层级。
