# 本地 PDF 翻译

桌面应用可按需下载 HY-MT2-1.8B Q4_K_M（约 1.13 GB）及当前平台运行器，无需安装 Ollama。支持 Mac Apple 芯片、Mac Intel 和 Windows x64；Mac Apple 芯片完成真实运行验证，其他两类平台尚待实机验收。模型与运行器独立存放，不随主安装包捆绑。

## 使用

1. 打开「设置 → AI 服务 → 本地翻译」，下载扩展。
2. 选段翻译：在 PDF 拖选一句或一段，点击标注工具中复制右侧的翻译图标。完成后可以复制译文或保存为标注；关闭按钮或浮层内 Esc 返回原标注工具。
3. 全文翻译：勾选「整篇 PDF 使用本地翻译」，在 PDF 阅读工具栏点击翻译。支持暂停、保存进度、退出重开后继续，并将完成译文另存为 PDF；不会覆盖原 PDF。

仅支持有文字层的 PDF 普通重排翻译，不包含 OCR 或恢复原版式。选段最多 4,500 字符，超限明确提示。专业术语仍可能误译，应结合原文阅读。选段与全文共用本地运行器，有任务运行时先暂停已有任务。

## 数据与运行

- 本地生成无需个人 Key 或体验凭据，不扣云端额度，失败不自动回退云端。
- 下载需要联网；正文只交给本机运行器处理。下载源、版本、文件大小及摘要固定在 `desktop/runtime/local-translation-manifest.json`，安装前验证。
- 统一通过 `resolveAiAccess` / `createAiTask` 管理本地 translation 任务。运行器仅绑定回环地址，临时令牌不交给界面，关闭、取消及退出会清理任务。
- 译文保存到当前工作区。保存为标注时保留已有笔记、原文和高亮位置，并追加译文。卸载模型不删除工作区或已保存译文。
- 第三方许可见 `licenses/local-translation/`；数学字体许可见 `public/assets/pdf-fonts/`。

## 验证边界

自动测试使用模拟模型，覆盖安装校验、完整输入、取消、任务清理、禁止云端回退、来源切换、旧结果隔离、全文保存续译及标注布局。

Mac arm64 真实验证包括 8 页文字 PDF 全文完成、保存第一个单元后暂停退出、重开仅继续剩余单元、完成后保存及导出；选段真实生成、独立浮层显示、关闭／Esc 返回、窗口缩放和保存标注也已验证。这些是功能验收，不代表专业翻译准确率。

Windows／Intel 实机、新电脑完整下载、完整亮色及签名发行包未验证。本次为源码更新，未发布新安装包。
