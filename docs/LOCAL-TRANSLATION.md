# 本地 PDF 翻译

桌面应用可按需下载 HY-MT2-1.8B Q4_K_M（约 1.13 GB）及当前平台运行器，无需安装 Ollama。支持 Mac Apple 芯片、Mac Intel 和 Windows x64；Mac Apple 芯片完成真实运行验证，其他两类平台尚待实机验收。模型与运行器独立存放，不随主安装包捆绑。

## 使用

1. 打开「设置 → AI 服务 → 本地翻译」，下载扩展。
2. 选段翻译：在 PDF 拖选一句或一段，点击标注工具中复制右侧的翻译图标。完成后可以复制译文或保存为标注；关闭按钮或浮层内 Esc 返回原标注工具。
3. 全文翻译（工具栏只保留本地翻译和导出，不再选择翻译版式）：勾选「整篇 PDF 使用本地翻译」，在 PDF 阅读工具栏点击翻译。支持暂停、保存进度、退出重开后继续，并将完成译文另存为 PDF；不会覆盖原 PDF。

仅支持有文字层的 PDF 普通重排翻译，不包含 OCR 或恢复原版式。选段最多 4,500 字符，超限明确提示。专业术语仍可能误译，应结合原文阅读。选段与全文共用本地运行器，有任务运行时先暂停已有任务。

普通译文支持 Markdown 标题、段落、列表、引用、强调和代码的限定排版，并根据原文位置保留单栏／双栏及跨栏标题和摘要。公式碎片紧凑显示，但不重建数学语义；图片和复杂表格仍需对照原文。预览与导出一致，已保存译文可直接重排，无需重新翻译。这项排版改进已纳入源码更新，尚未发布。

独立成行且位置可靠的公式及编号可从原 PDF 原样裁取，以高清图片嵌入预览和导出，不必重译。行内公式、混合正文、旋转或位置不可靠的页面保持现状。译文不再额外添加顶部品牌及底部横线、页码和说明。该改进已纳入源码更新并经 Mac 真实论文验证，未发布；Windows／Intel 实机未测。

双栏译文会按阅读顺序均衡分配内容，并有限调整间距让两栏底部对齐；跨栏标题／摘要及完整公式保留。每张译文页使用对应原文页的实际宽高，内容多时收紧空白、缩小字号并重新换行，必要时等比缩放，不裁掉内容或增加页高。普通翻译按页边同步滚动，悬停保留对应高亮但不再单侧跳滚。该改进已纳入源码更新，预览和导出一致，无需重译，尚未发布。

## 连续划词（源码更新、未发布）

成功翻译后模型待命 5 分钟，期间再次翻译直接复用；首次使用或闲置释放后仍需加载，待命期间会占用模型内存。取消、失败、卸载和退出停止模型。关闭已完成的译文不打断待命，全文与选段仍一次只运行一个任务。

已保存高亮可直接重新划词；单击仍编辑原标注。标注工具提供拖动手柄，编号和区域摘录也可拖到画板。蓝色选区内可立即重选，修正同一行窄词间空隙的错误选区终点，避免多选下面的行；大尺寸页面切换缩放时文字层不会错误复用。

## 数据与运行

- 本地生成无需个人 Key 或体验凭据，不扣云端额度，失败不自动回退云端。
- 下载需要联网；正文只交给本机运行器处理。下载源、版本、文件大小及摘要固定在 `desktop/runtime/local-translation-manifest.json`，安装前验证。
- 统一通过 `resolveAiAccess` / `createAiTask` 管理本地 translation 任务。运行器仅绑定回环地址，临时令牌不交给界面，关闭、取消及退出会清理任务。
- 译文保存到当前工作区。保存为标注时保留已有笔记、原文和高亮位置，并追加译文。卸载模型不删除工作区或已保存译文。
- 第三方许可见 `licenses/local-translation/`；数学字体许可见 `public/assets/pdf-fonts/`。

## 验证边界

自动测试使用模拟模型，覆盖安装校验、完整输入、取消、任务清理、禁止云端回退、来源切换、旧结果隔离、全文保存续译及标注布局。

Mac arm64 真实验证包括 8 页文字 PDF 全文完成、保存第一个单元后暂停退出、重开仅继续剩余单元、完成后保存及导出；选段真实生成、独立浮层显示、关闭／Esc 返回、窗口缩放和保存标注也已验证。这些是功能验收，不代表专业翻译准确率。

Windows／Intel 实机、新电脑完整下载、完整亮色及签名发行包未验证。本次为源码更新，未发布新安装包。

## 行内公式原图保留（源码更新、未发布）

本地普通全文翻译可对文字 PDF 中可靠识别的行内公式保留原图、基线和上下标，译文翻译周围正文。旧完整译文通过译文状态栏的“还原行内公式”升级；只重译受影响的段落及必要边界，其他正文复用。每段保存来源签名与公式对应，暂停后只继续未验证部分。模型漏标记、重复或未知标记时拒绝原回执，并在同一任务内做一次分段修复，由程序固定公式、模型只翻译相邻文字；再次失败时停止且保留已完成结果，不重发原句或无限重试。兜底句段的中文衔接可能生硬。预览及导出共用原图，保持原 PDF 逐页宽高。

只支持能可靠确定边界的公式；复杂跨行、扫描、旋转及特殊坐标页不猜测，不提供可编辑公式或完整 OCR。Windows／Intel 实机及发行包尚未验收。
