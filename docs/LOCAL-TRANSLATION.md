# 本地 PDF 翻译

本地 PDF 翻译已随官方桌面版 Mac Apple 芯片 `0.1.43` 和 Windows x64 预览版 `0.1.43-win.1` 发布。社区源码也包含此功能，社区构建使用独立版本号。 [官方下载](https://lumior.work/)

桌面应用按需下载 HY-MT2-1.8B Q4_K_M 模型和当前平台的运行组件，合计约 1.15–1.16 GB，安装时请预留约 1.8 GB 空闲空间。下载完成后可离线使用，无需安装 Ollama。社区源码配置了 Apple 芯片 Mac、Intel Mac 和 Windows x64 的运行组件，真实模型流程已在 Apple 芯片 Mac 验收。

## 使用

1. 打开「设置 → AI 服务 → 本地翻译」，下载扩展。
2. **选段翻译。** 在 PDF 拖选一句或一段，点击标注工具中复制按钮右侧的翻译图标。可以复制译文或保存为标注。关闭浮层或按 Esc 返回原标注工具。
3. **全文翻译。** 勾选「整篇 PDF 使用本地翻译」，在 PDF 阅读工具栏点击翻译。可以暂停、保存进度、退出重开后继续，并将完成译文另存为独立 PDF。

翻译适用于有文字层的 PDF，选段最多 4,500 字符。专业术语建议对照原文核查。选段与全文共用本地运行器，一次执行一个任务。

## 对照阅读与公式

译文按标题、段落和原文栏数重新排版，支持有限的 Markdown 样式和跨栏标题、摘要。每张译文页与对应原文页宽高一致，两侧按页同步滚动。预览与导出使用相同排版。内容密集时可能缩小字号，图片和复杂表格建议结合原文查看。

可可靠定位的独立和行内公式以原 PDF 裁片保留在预览与导出中，包括可可靠定位的公式编号。旧译文可从译文状态栏选择「还原行内公式」，只会重译受影响的段落及必要边界。发生行内公式完整性错误时，同一任务最多做一次分段修复，再失败会保留已完成结果。

扫描件 OCR、可编辑公式、复杂跨行或旋转公式、逐元素还原原版式均超出当前支持范围。

## 连续划词

成功翻译后模型待命 5 分钟，期间再次翻译直接复用；首次使用或闲置释放后仍需加载，待命期间会占用模型内存。取消、失败、卸载和退出停止模型。关闭已完成的译文不打断待命，全文与选段仍一次只运行一个任务。

已保存高亮可直接重新划词；单击仍编辑原标注。标注工具提供拖动手柄，编号和区域摘录也可拖到画板。蓝色选区内可立即重选，修正同一行窄词间空隙的错误选区终点，避免多选下面的行；大尺寸页面切换缩放时文字层不会错误复用。

## 数据与运行

- 本地生成无需个人 Key 或体验凭据，不扣云端额度，失败不自动回退云端。
- 下载需要联网；正文只交给本机运行器处理。下载源、版本、文件大小及摘要固定在 `desktop/runtime/local-translation-manifest.json`，安装前验证。
- 统一通过 `resolveAiAccess` / `createAiTask` 管理本地 translation 任务。运行器仅绑定回环地址，临时令牌不交给界面，关闭、取消及退出会清理任务。
- 译文保存到当前工作区。保存为标注时保留已有笔记、原文和高亮位置，并追加译文。卸载模型不删除工作区或已保存译文。
- 第三方许可见 `licenses/local-translation/`；数学字体许可见 `public/assets/pdf-fonts/`。

## 验证边界

自动测试使用模拟模型，覆盖安装校验、完整输入、取消、任务清理、禁止云端回退、来源切换、旧结果隔离、全文保存续译及标注布局。

Mac arm64 真实验证包括 8 页文字 PDF 全文完成、保存第一个单元后暂停退出、重开仅继续剩余单元、完成后保存及导出；选段真实生成、独立浮层显示、关闭／Esc 返回、窗口缩放和保存标注也已验证。这些是功能验收，不代表专业翻译准确率。

Windows x64 和 Intel Mac 实机、新电脑首次下载全流程、原生自动更新安装与重启、完整亮色验证仍待补充。
