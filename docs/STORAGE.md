# 数据与备份

工作区结构与附件保存在本地。桌面社区版、社区开发版和官方版使用不同的数据目录；浏览器数据则与浏览器及访问地址绑定。卸载前或清理浏览器数据前，请先制作备份。

已有笔记继续使用原存储格式。新导入的 Obsidian 库把每篇原文单独保存，工作区只保留目录、标题与稳定身份；打开或交给 AI 阅读时再取正文。编辑后的内容单独保存，保存失败会显示错误，不以空正文覆盖原稿。

导入是复制，不回写或同步原 Obsidian 文件夹。导入前先建立全库路径索引，所以双链可以指向尚未打开的笔记；重名不明确时保留原文字，不随意跳到另一篇。已有内部引用在移动、重命名与备份恢复中按稳定身份处理。

新导入支持标题和路径检索。全文检索、反向链接列表和关系图尚未实现；带标题片段的链接目前打开整篇笔记。

大库建议使用“备份到文件夹”和“选择备份文件夹”。程序分块复制附件并校验，保留正文与内部引用。请不要只复制工作区结构文件，遗漏单独保存的正文与附件。旧 ZIP 备份入口继续存在，但不适用于数 GB 的库。

当前实现设有文件数、单文件和总大小保护，这些数值不是所有硬件都已验证的性能承诺。Windows 的大库导入及目录备份/恢复仍需实机验收。社区测试使用合成资料，不应要求报告者上传真实知识库。
