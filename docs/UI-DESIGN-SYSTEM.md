## 本轮收敛结果

- 统一色板：**44 项用途，38 个不同色值**，包含透明色和阴影；上限 50。首次收敛为 42 个色值，后按用户确认的四组灰阶进一步合并。
- 原扫描 719 种颜色写法先降到 142 种，四组灰阶合并后为 138 种。138 包含色板定义和内容例外，不能声称整个项目只剩 44 个色值。
- 82 个 CSS 文件的 2,471 处声明迁移；同时移除全局重复的旧明暗色定义，接入基础控件、内联样式和缩略图。
- 受管的界面色值未登记项为 0；当前扫描保留 156 处内容 / 绘画色引用。色谱等命名色由检查器单独覆盖。
- 菜单删除保留红字与中性悬停；通用删除按钮、论文删除和文件删除确认使用危险淡底 / 深红实底与白字。
- 白色 10% 选中、8% 悬停、14% 按下分别命名。输入区、菜单、卡片、滚动条引用同一套用途色。

真值文件是 `design-system/ui-palette.json`。`app/ui-colors.css` 由它生成，`globals.css` 只保留旧语义名到新色板的别名。审查台的暗色预览也读取同一份色板；手动预览调色及亮色方案不会直接写回产品。

`colors:check` 检查 50 项上限、生成文件同步、未知 UI 变量、受管 CSS / TS 颜色字面量和 Tailwind 任意色 / 常见内置色。它不是运行时全部像素计数，也不穷尽动态 SVG、第三方依赖内部颜色或用户文档内容。

颜色合并须保留渐变和遮罩的透明度关系。空间渐隐可从现有规范色通过 `color-mix(..., transparent)` 派生透明度；完全透明的端点必须保留 `transparent`，不能就近映射成实色、阴影或普通遮罩色。`mask-image` 中的透明度决定遮挡范围，不能把同一黑色的不同透明度全部替换成实黑。规范检查通过只说明颜色来源合规，不能代替叠在卡片、文字和图片上时的视觉验收。

删除危险文字为 `#f4776b`；白字实底为 `#b73f34`。前者直接配白字约 2.73:1，后者约 5.56:1，已应用本地产品。浅底动作使用深色文字。

普通文本的 4.5:1 参考、大文本的 3:1 参考，以及禁用内容和标志的例外，见 [W3C WCAG 2.2 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。透明色须与实际背景合成；单个配对通过不等于整个界面符合 WCAG。

## 已确认的灰阶共用（2026-10-25）

| 共用用途 | 统一色值 | 处理 |
| --- | --- | --- |
| 控件底色、突出控件 | `#303133` | 合并两档相近控件灰 |
| 次要文字、辅助文字 | `#a3a3a3` | 合并相邻说明文字层级 |
| 主要文字、反白与白底动作 | `#ffffff` | 共用白色 |
| 浅底上的深字、内容表面 | `#191919` | 共用深灰 |

18 项讨论范围内的用途由 16 个色值降至 12 个；全色板由 42 降至 38。用途名称不删除：亮色时文字与背景仍可分别映射。内容表面 / 浮层、禁用文字、边框强弱和交互状态保持区分；白色 10% 选中底不变。未额外删除成功淡底或合并阴影。

统一后的说明文字在内容表面上对比度约 6.97:1，在最亮的实底悬停灰上约 4.65:1；浅底深字在白底上约 17.58:1。这里只核对色板配对，不能替代所有透明叠层的运行时检查。

## 已采用的颜色结构与亮色准备

颜色按用途集中定义，旧组件变量作为别名接入。业务组件引用“它为什么用这个颜色”，不引用“它碰巧是几号灰”。

| 用途组 | 建议角色 | 亮色处理 |
| --- | --- | --- |
| 表面 | 画布、内容、浮层、普通控件 | 分别映射浅灰与白色，保留层级和边界 |
| 文字 | 主要、次要、辅助、反色 | 分别配深浅，不将所有文字一起反转 |
| 交互 | 悬停、选中、焦点、禁用、输入边界 | 白色低透明覆盖改为深色低透明覆盖 |
| 主操作 | 主按钮底色、主按钮文字 | 暗色为白底深字；亮色为近黑底白字，图标跟随文字 |
| 品牌强调 | 品牌色、进度、选中描边／焦点 | 保留荧光绿；亮色文字与必要焦点另用深绿，不替代主按钮底色 |
| 状态 | 成功／进行中、关注、错误、危险动作 | 深浅各配明度，状态仍附带形状或说明 |
| 内容类型 | 文献、NotePage、画板、视频、图片 | 保留色相身份，调整明度与对比 |

PDF 文本和图片原文、用户标注、自定义分区色、内容图片、播放器及供应商标志单独登记。不要用全局滤镜或色值搜索替换改动这些内容。

主操作使用 `--action-primary` / `--action-primary-foreground`，暗色复用色板的 `white` / `ink`，不增加色板项。通用 Button、数据设置、更新通知与探索采纳按钮已接入。旧 `--primary` 仍作为品牌强调别名供选中描边、进度和选择控件使用，避免修改主按钮时连带改变这些状态。亮色近黑按钮已体现在审查台方案中，完整亮色产品尚未接入。

## 验证与后续边界

本轮属于颜色迁移，不重构业务组件和数据，不修改现有用户画板。保留的内容例外有回归快照；常用文字 / 背景、危险按钮及主色按钮检查真实色板对比度。

完成项：颜色边界检查、类型检查、组件库构建、颜色与内容保护测试；真实产品在独立本机端口使用空工作区核对首页、画布、输入区和多维表预览。独立组件审查台核对菜单、论文提醒、选中态和按钮尺寸。没有将这些检查称为全系统无障碍验收；原生桌面安装与完整 PDF / 多维表业务流程未重跑。

下一步亮色适配单独推进：

1. 按现有用途补亮色值，尤其是主色文字、状态色、边框和透明叠层。
2. 复核编辑器、PDF、媒体、多维表及第三方组件；保留内容原色。
3. 接入主题选择与持久化，核对原生窗口、首次绘制和系统跟随。
4. 在用户确认后准备桌面发布。

## 日常维护

- 修改颜色：编辑色板 → `colors:sync` → `colors:check` → `design:scan`。
- 查看用途：`design:dev` →「44 项规范色」→ 每项先展示组件配色示例，点击「查看 / 比较」定位作用层并试换颜色；实际来源及其他 CSS 直接 / 别名引用可展开。真实组件、简化原型和未使用色分开标注。
- 进一步收敛：先在审查台保留试配与删除候选，导出建议后再决定产品改动；不会自动更新色板。同色用途不会再次减少色值；`success-soft` 当前无产品引用，是删除候选。
- `design:build` 生成本地可审查页面；不发布产品。
- 一次迁移明细与之前 CSS 副本在 `output/color-consolidation/`，不可用它覆盖后续用户修改。`scripts/consolidate-ui-colors.mjs` 仅为本次迁移记录，不属于构建中的自动改色流程。

## Note 排版（2026-10-29）

正文、标题等级、实际行高集中维护在 `app/document-typography.css`。各显示入口只调整容器几何和留白，不再独立覆盖 H1–H4 字号。

| 参数 | 画板卡片 | 展开 Note |
| --- | --- | --- |
| 独立 Title | 24px / 31px 行高 | 28px / 1.45 行高 |
| Title 后间距 | 12px | 28px |
| H1 / H2 / H3 / H4 | 24 / 20 / 18 / 16px | 24 / 20 / 18 / 16px |
| 标题行高 | 1.5 | 1.5 |
| 标题上下外边距 | 各 8px | 各 10px |
| 正文 | 14px / 21px 行高 | 15px / 22.5px 行高 |

Title 使用独立的 `--note-title-*` 参数，不参与正文标题转换。斜杠菜单、格式菜单和标题快捷键提供 H1–H4；历史或导入的 H5/H6 保留原结构，按 H4 字号显示。BlockNote 的标题容器和内层文字共同控制字号，实际块行高也显式覆盖，避免只改编辑器根元素却未生效。

## 外框与导航（2026-10-29，本地未发布）

- 顶部标签栏、左侧窄导航轨道和外沿共用外框表面：桌面端 `color-mix(in srgb, var(--ui-surface) 55%, transparent)`，模糊 `28px`，饱和度 `110%`。AI 输入框继续使用原 `--ui-glass`，约 90.2% 不透明度。
- Mac 使用深色原生 `under-window` 材质；Windows 11 22621 及以上使用 acrylic，旧 Windows / Web / Linux 保留不透明兜底。原生背景写明确 alpha 色 `#00000000`，Electron 的命名色解析不识别 CSS 关键字 `transparent`，会退回白色。
- 星海 Hub 的路径占满 viewBox，20px 的实际图形与其他 24px 图标的内侧图形接近；按钮仍为 36px、圆角 12px。常态图形 60% 白色，hover / 选中 80%，选中用 filled 资产。
- 画板右上方手电筒、侧栏、卡片库及更多菜单的 Tooltip 向下显示。首页范围搜索为 28px 图标按钮，展开向左延伸；全局搜索单独使用对话框。

## 卡片顶栏与图片缩放（2026-10-29，本地未发布）

- 单卡与多选顶栏统一使用图标加短标签，不混用无文字按钮。单卡依内容显示「问 AI」「展开 / 预览」「卡片盒」「原文」「笔记」「适应内容」「字幕」「更多」；Tooltip 保留完整说明。窄空间将次要操作移入更多，保留在外的操作仍显示文字。
- 普通图片选中后显示四角缩放手柄，固定原图比例及对侧图片角；图片最长边为 120–1600 画板像素（不含边框），数值集中在 `app/card-sizing.ts`。备注文字保持原字号，随宽度自然换行。此限制用于用户缩放，不主动重排既有图片；不改变图片源文件。
- 图片缩放支持撤销 / 重做、Esc 或失焦取消，以及保存后恢复；不改 PDF 摘录或侧栏预览的布局。
