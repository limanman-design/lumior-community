# AI 与资料流向

画板、笔记、附件和编辑记录默认保存在当前浏览器或桌面应用的本地工作区。社区构建不提供云同步，也不附带官方模型额度。

个人 Key 模式将用户请求及完成该功能所需的上下文发送给所选供应商；用户需自行承担供应商费用。对话、翻译、MBA 助手等复用同一个授权与任务入口。不存在“官方额度耗尽后自动改用个人 Key”的回退。

官方发行可以配置官方体验/收费服务。用户明确选择该模式后，请求经过官方服务执行授权和额度控制，再转交模型供应商。开源仓库包含客户端协议，不包含官方网关、账本与后台的实现或数据。

资料的本地保存不等于 AI 请求不发送资料。对选定文档提问或翻译时，程序需要读取并发送相应内容；大型 Obsidian 笔记按需读取，读取失败不能只用标题冒充正文。模型调用前请确认资料适合发送给所选服务。

联网功能还包括主动打开视频、检索公开书目记录、刷新模型目录等。广播与第三方网络资源不属于开源许可授予的内容。源码与网络行为应一同审阅。

普通贡献 CI 只使用合成凭据与模拟上游，不运行收费模型请求，也不需要访问真实个人工作区。
